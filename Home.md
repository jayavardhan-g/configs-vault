# Home

Jayavardhan's config and decisions log, as a linked vault. Every entry records one change
(what, why, the exact config, gotchas), and links to the tools it touches.

## How it's linked

- **Hubs** (`hubs/`): one per area. Start here.
- **Entities** (`entities/`): one short note per tool or component (Hyprland, kitty,
  BitLocker…). Open one and its **backlinks** list every decision that touches it.
- **Entries** (everything else): each has a `**Graph:**` line linking its entities.
- **Claude's memory** (`claude-memory/`): preferences, shelved plans and facts Claude
  keeps between sessions, linked to the same entities.

Links are generated by `python3 scripts/build-graph.py`; see [[CLAUDE]] for the rules.
